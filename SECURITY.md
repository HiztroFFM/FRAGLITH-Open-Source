# Security Policy

FRAGLITH is currently a community/documentation repository and has no published production server software under this repository.

## Reporting issues

- **Do not** post passwords, tokens, server credentials, private conversations, or exploit details in public issues.
- For a sensitive report, contact the repository maintainer privately via the contact options on [their GitHub profile](https://github.com/HiztroFFM).
- If GitHub's private vulnerability reporting is enabled in this repository, you can use its **Report a vulnerability** feature.

For non-sensitive documentation mistakes or ordinary bugs, [open a public issue](https://github.com/HiztroFFM/FRAGLITH-Open-Source/issues).

We do not currently make a formal response-time or supported-version guarantee.

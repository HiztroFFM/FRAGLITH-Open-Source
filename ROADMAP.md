# FRAGLITH Roadmap

> Public roadmap: planned work is not a promise of a release date.

## Phase 1 — Community foundation

- [x] Publish community introduction and Discord invite
- [x] Add contribution guidelines
- [x] Add issue/PR templates, conduct rules, and starter resources
- [x] Publish privacy-safe historical CS2 troubleshooting notes
- [x] Publish a standalone local log-triage script and tests
- [ ] Recruit volunteer maintainers and reviewers
- [ ] Gather first community feedback

## Phase 2 — Learning resources

- [x] Link to official/community CS2 development documentation
- [ ] Write and validate a minimal **SwiftlyS2 C# plugin** example
- [ ] Document a reproducible 3D model-to-CS2 workflow using distributable test assets
- [ ] Build an AG2 animation troubleshooting guide tested against current CS2 tools
- [ ] Provide Turkish and English beginner walkthroughs

## Phase 3 — Community projects

- [ ] Review and publish community-owned open-source plugins
- [ ] Build a catalog of verified code snippets and templates
- [ ] Add sample projects with tests and reproducible builds
- [ ] Collect compatibility reports after major CS2 updates

## How to help

Browse [Issues](https://github.com/HiztroFFM/FRAGLITH-Open-Source/issues), make a specific proposal, or join [Discord](https://discord.gg/Aq8NgGswN).

**Policy:** Never upload ripped, paid, leaked, or otherwise unauthorized game assets. A technique can be explained without redistributing the underlying copyrighted material.

# Türkçe özet

FRAGLITH'in hedefi CS2 eklentileri, model portlama ve AG2 animasyonları için **doğrulanmış, paylaşılabilir** kaynaklar geliştirmek. Yukarıdaki işaretli maddeler tamamlandı; boş kutular henüz plan aşamasındadır.

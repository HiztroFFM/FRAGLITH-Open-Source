# Getting Started with CS2 Development

Welcome to FRAGLITH! This page helps you choose a track and ask better technical questions.

## Pick your track

### A. Server plugin development

1. Choose a framework: [SwiftlyS2](https://swiftlys2.net/docs/) **or** [CounterStrikeSharp](https://docs.cssharp.dev/).
2. Read its current requirements and installation guide. Different frameworks are not API-compatible.
3. Follow the framework's official first-plugin example on a **test server**, not on a production server.
4. Save your code, the dependency/framework versions and the command you used to build.
5. Share the smallest example that reproduces any issue.

For SwiftlyS2, see [official getting started](https://swiftlys2.net/docs/development/getting-started/).

### B. 3D model and animation work

1. Learn the basics of Blender: meshes, UVs, material slots, armatures and animation actions.
2. Install CS2 Workshop Tools and create a separate test addon.
3. Check [the model/animation checklist](MODEL-AND-ANIMATION.md).
4. Test with original or appropriately licensed assets only.
5. Keep separate records of Source 2 compile output and in-game behavior.

### C. Documentation and support

Not everyone has to write plugins. You can improve Turkish translations, add screenshots to self-authored tutorials, verify old instructions against updated tools, or help reproduce bugs.

## Ask for help effectively

Include:

- What you are trying to do
- CS2 and tool versions
- Exact error log or screenshot
- Steps to reproduce
- What you already tried
- A small reproducible sample, where distribution is permitted

Do not share server passwords, tokens, personal details or unauthorized paid game assets.

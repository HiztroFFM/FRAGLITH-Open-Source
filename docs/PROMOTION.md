## Suggested community announcement (English)

### FRAGLITH • Open Source | CS2 Development & Source 2 Community

We're building a welcoming, free learning community for Counter-Strike 2 developers, model creators and beginners.

We publish **technical guides** on SwiftlyS2 / CounterStrikeSharp, Workshop deployment, Blender / Source 2 models, AG2 animations and VData troubleshooting. Our GitHub also includes a small, original Python utility for summarizing CS2 log error categories.

This is a **documentation and learning project** today, not a claimed release of ready-to-use CS2 model packs or plugins. Contributions, corrections and original examples are welcome.

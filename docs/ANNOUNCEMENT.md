## English — Developer communities

### FRAGLITH • Open Source

We're building an open community for Counter-Strike 2 developers and creators.

Our focus: **CS2 plugin development, SwiftlyS2 / CounterStrikeSharp, Blender and Source 2 model workflows, AG2 animation troubleshooting, technical docs, and open learning**.

Our GitHub now hosts getting-started resources, contribution guidelines, a public roadmap, and beginner-friendly issues. Working sample projects are on our roadmap, not yet published.

If you're learning CS2 development or want to help write useful guides, you're welcome to join.

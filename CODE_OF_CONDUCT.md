# FRAGLITH Community Code of Conduct

FRAGLITH aims to be a respectful, learning-focused community for Counter-Strike 2 developers, artists and newcomers.

## Expected behavior

- Be helpful and patient with beginners.
- Critique code and ideas, not people.
- Give credit to original authors.
- Explain limitations and uncertainty instead of presenting guesses as facts.
- Keep personal messages and private information private unless their author permits sharing.

## Unacceptable behavior

- Harassment, threats, hate speech, humiliation or personal attacks.
- Sharing private conversations, contact information or credentials without consent.
- Selling or redistributing somebody else's work without the appropriate rights.
- Plagiarism, knowingly misleading technical claims or deceptive attribution.
- Repeated unsolicited advertising and off-topic disputes.

## Moderation

Maintainers may remove violating content or limit participation when needed. Report concerns privately to a project maintainer through GitHub or the Discord community's available moderator contact route. Do not publish sensitive details in a public GitHub issue.

## Scope

This code applies to repository issues, pull requests, discussions related to FRAGLITH and community spaces run by FRAGLITH.
